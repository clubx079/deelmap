Design specifications

Border treatment 2px gradient wrapper (135°, #D03839 → #E8633E → #D03839) — renders as a true gradient border without affecting layout
Glow & shadow 4px rgba(208,56,57,0.10) ring + 32px rgba(208,56,57,0.18) ambient glow — pulses on a 3s ease loop
Photo top stripe 3px gradient bar (same red–orange) via ::after pseudo — signals premium on scroll before reading content
Highlighted badge Gradient pill on photo (white text) — more visible than a content-area badge, catches eye immediately
Metrics row Asking / ARV / Cash-on-Cash — three separated columns replace the inline stat string, communicates investment value at a glance
CTA button Filled #D03839 + red shadow (0 2px 10px rgba(208,56,57,0.28)) — primary action is red on highlighted cards, black on standard cards
